## Detailed Findings

### P0 — Side-stripe borders (3 violations, absolute ban)
- **Locations:** `.why-built h2` (~line 696), `.rec-item` (~line 452), `.econ-context` (~line 720)
- **Fix:** Remove all `border-left` accent treatments.
  - `.why-built h2`: leading `::before` square or rely on weight + color
  - `.rec-item`: full `background: var(--cream)` + numbered step indicator (reuse `qw-card` pattern already on page)
  - `.econ-context`: full border + subtle `background: #f8f8f5`
- **Command:** `/impeccable colorize`

### P1 — No aria-live on results
- **Location:** `<div class="results" id="resultsSection">`
- **Impact:** Screen reader users submit form and hear nothing. WCAG 4.1.3 failure.
- **Fix:** Add `aria-live="polite" aria-atomic="false"` to results container; `aria-busy="true"` on form during loading
- **Command:** `/impeccable harden`

### P1 — Setup screen not a dialog
- **Location:** `<div class="setup-screen" id="setupScreen">`
- **Impact:** No focus trap, no role announcement for screen readers
- **Fix:** Convert to `<dialog>` with `showModal()` or add JS focus-trap + `role="region"`
- **Command:** `/impeccable harden`

### P1 — SWOT card colors disconnected from brand palette
- **Location:** `.swot-s`, `.swot-w`, `.swot-o`, `.swot-t` — using Material Design green/orange/blue/red
- **Impact:** Strongest "AI assembled this from training data" tell in the file. Off-brand.
- **Fix:** Rethink using brand palette (olive-light for strength, cream+accent for weakness, neutral tints for opportunity/threat)
- **Command:** `/impeccable colorize`

### P1 — text-light #666666 borderline on cream
- **Location:** `.setup-sub`, `.hint`, `.intro p`, `.cta-card p`, `.loading p`
- **Impact:** ~5.0:1 on cream barely passes AA; functionally fails at 0.82rem hint text
- **Fix:** Darken `--text-light` to `#5A5A5A`
- **Command:** `/impeccable colorize`

### P2 — Readiness badge approaching hero-metric template
- **Location:** `.readiness-badge` + `.readiness-benchmark`
- **Fix:** Convert to a plain sentence: "Your readiness score is 67 — above the Ontario trades average of 52"
- **Command:** `/impeccable clarify`

### P2 — 30+ hardcoded one-off colors not in token system
- **Location:** Demo banner (#FFF9C4, #F9A825, #5D4037), PIPEDA note (#f0f4ff, #c5d5f0, #1a2744), header text (#B0B0A8)
- **Fix:** Extend `:root` with `--color-banner-bg`, `--color-info-bg`, `--color-muted-text` tokens
- **Command:** `/impeccable extract`

### P2 — CTA card gradient (decorative)
- **Location:** `.cta-card` — `linear-gradient(135deg, #F5F0E8 0%, #EDE8DF 100%)`
- **Fix:** Replace with flat `background: #EDE8DF`
- **Command:** `/impeccable colorize`

### P3 — SWOT identical card structure
- **Fix:** Differentiate quadrant treatments (checkmark motif for Strengths, different visual weight for Threats)
- **Command:** `/impeccable delight`

### P3 — econ-metrics flex overflow at 320px
- **Fix:** Add min-width constraints to metric items
- **Command:** `/impeccable adapt`
